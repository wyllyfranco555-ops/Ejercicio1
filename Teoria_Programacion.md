- double

- boolean

# 16. ¿Cómo funcionan if, else, switch y los bucles en Java?

- if: ejecuta código cuando una condición es verdadera.
- else: ejecuta código cuando la condición del if es falsa.
- switch: permite seleccionar diferentes acciones dependiendo del valor de una expresión.
- Bucles (for, while, do-while): permiten repetir instrucciones mientras se cumpla una condición o durante un número determinado de veces.

# 17. ¿Por qué es importante usar nombres significativos para variables y métodos?

Porque hacen que el código sea más fácil de leer, entender, mantener y modificar. Por ejemplo, edadUsuario es más claro que utilizar simplemente x.

# 18. ¿Qué es la Programación Orientada a Objetos (POO)?

Es un paradigma de programación que organiza el código utilizando objetos y clases. Los objetos representan entidades que poseen atributos y comportamientos.

# 19. ¿Cuáles son los cuatro pilares de la POO?

Son: 

1. Encapsulamiento: protege y controla el acceso a los datos de un objeto.
2. Abstracción: permite mostrar las características importantes y ocultar detalles innecesarios.
3. Herencia: permite que una clase adquiera características y comportamientos de otra.
4. Polimorfismo: permite que un mismo método o interfaz tenga diferentes comportamientos dependiendo del objeto.

# 20. ¿Qué es la herencia en POO y cómo se utiliza en Java?

La herencia permite crear una clase basada en otra, heredando sus atributos y métodos. En Java se utiliza principalmente mediante la palabra clave extends.

# 21. ¿Qué son los modificadores de acceso y cuáles son los más comunes?

Controlan quién puede acceder a clases, atributos y métodos. Los más comunes son:

- public: accesible desde cualquier lugar.
- private: accesible únicamente dentro de la misma clase.
- protected: accesible dentro del mismo paquete y desde clases hijas.
- Sin modificador: accesible dentro del mismo paquete.

# 22. ¿Qué es una variable de entorno y por qué es importante para Java?

Es un valor configurado en el sistema operativo que puede ser utilizado por los programas. En Java son importantes, por ejemplo, variables como JAVA_HOME y PATH, que ayudan al sistema a localizar el JDK y ejecutar comandos de Java.
